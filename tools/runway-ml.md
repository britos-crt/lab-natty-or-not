# 🎬 Runway ML

> Plataforma de geração e edição de vídeos com IA, referência em criação de conteúdo visual generativo.

---

## 🔗 Acesso

- **Site oficial:** [https://runwayml.com](https://runwayml.com)
- **Plano gratuito:** 125 créditos iniciais
- **Planos pagos:** A partir de US$ 15/mês
- **Modelos:** Gen-2, Gen-3 Alpha

---

## 📋 O que é?

O **Runway ML** é uma das plataformas mais avançadas para **geração e edição de vídeos com IA**.
Permite gerar vídeos a partir de texto (text-to-video), transformar imagens em vídeos (image-to-video),
editar vídeos existentes com IA e remover/substituir elementos visuais automaticamente.

---

## 🏋️ Como usar no contexto "Natty or Not"?

### 1. Geração de Vídeo (Text-to-Video)
Crie cenas conceituais sobre fisiculturismo natural:

```
Prompt Gen-3:
"A muscular natural athlete training in a gym, cinematic lighting,
slow motion, documentary style, realistic physique, no exaggerated muscles"

→ Gera clipe de 4-10 segundos de alta qualidade
```

### 2. Transformação de Imagem em Vídeo (Image-to-Video)
```
1. DALL·E 3 / Midjourney → gera imagem de atleta
2. Runway ML → anima a imagem (movimentos, iluminação)
3. ElevenLabs → adiciona narração
= Vídeo educativo completo sobre o tema
```

### 3. Edição Inteligente de Vídeos
- **Remove fundo** automaticamente de vídeos de treino
- **Aplica efeitos cinematográficos** com um clique
- **Inpainting de vídeo:** remove ou substitui elementos visuais

### 4. Criação de B-roll para YouTube
```
Para um vídeo sobre "Natty or Not":
- Cenas de treino em academia (text-to-video)
- Close de músculos em câmera lenta (image-to-video)
- Transições cinematográficas automáticas
```

## 🎛️ Principais Recursos

| Recurso | Descrição |
|---|---|
| **Gen-3 Alpha** | Geração de vídeo text-to-video de última geração |
| **Image-to-Video** | Anima qualquer imagem estática |
| **Video-to-Video** | Transforma o estilo de um vídeo existente |
| **Inpainting** | Edita partes específicas do vídeo |
| **Green Screen** | Remoção automática de fundo |
| **Motion Brush** | Controla direção do movimento no vídeo |

## ⚠️ Limitações

- Créditos se esgotam rapidamente nos planos básicos
- Vídeos longos consomem muitos créditos
- Geração de vídeos realistas com pessoas ainda pode ter artefatos
- Não permite geração de conteúdo violento ou sexual
