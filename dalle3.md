# 🎨 DALL·E 3 (OpenAI)

> Modelo de geração de imagens da OpenAI, integrado ao ChatGPT e à API da plataforma.

---

## 🔗 Acesso

- **Via ChatGPT:** [https://chat.openai.com](https://chat.openai.com) (planos Plus/Pro)
- **Via API:** [https://platform.openai.com](https://platform.openai.com)
- **Bing Image Creator:** [https://www.bing.com/create](https://www.bing.com/create) (gratuito)

---

## 📋 O que é?

O **DALL·E 3** é o modelo de geração de imagens da OpenAI, capaz de criar ilustrações altamente detalhadas
a partir de descrições em linguagem natural. É integrado nativamente ao ChatGPT, permitindo
criar imagens sem sair do fluxo da conversa.

---

## 🏋️ Como usar no contexto "Natty or Not"?

### 1. Ilustrações Educativas
Gere imagens que ilustrem conceitos científicos sobre hipertrofia:

```
"Crie uma ilustração científica mostrando a diferença visual entre
fibras musculares de um atleta natural e um atleta que usa esteroides."
```

### 2. Comparativos Visuais de FFMI
```
"Gere uma infografia visual comparando silhuetas corporais em diferentes
níveis de FFMI (20, 22, 25, 27, 30) com labels educativos."
```

### 3. Conteúdo para Redes Sociais
```
"Crie uma arte para post de Instagram com o tema 'Fisiculturismo Natural:
A Jornada Real', estilo moderno, cores escuras e vibrantes, sem texto."
```

### 4. Diagramas Conceituais
```
"Ilustre o conceito de 'teto natural' de hipertrofia muscular como um
gráfico visual com um atleta construindo seu físico ao longo de anos."
```

---

## ⚠️ Limitações

- **Não gera rostos reais** de pessoas públicas sem consentimento
- Pode recusar prompts que envolvam representações corporais muito específicas
- Menor controle estilístico do que Midjourney ou Stable Diffusion
- Geração de texto dentro de imagens ainda limitada

---

## 💡 Dica de Prompt para o Tema

```
Crie uma ilustração estilo infografia científica mostrando:
- À esquerda: atleta natural com FFMI 22, rótulo "Natural - 10 anos de treino"
- À direita: atleta com uso de substâncias com FFMI 28, rótulo "Assistido"
- No centro: gráfico de linha mostrando a diferença de progressão
Estilo: moderno, clean, fundo branco, paleta azul e cinza.
```
