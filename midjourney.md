## 📋 O que é?

O **Midjourney** é um dos modelos de geração de imagens mais avançados do mundo, conhecido por
produzir resultados **hiper-realistas e artisticamente refinados**. Opera principalmente via Discord,
onde os usuários enviam prompts em canais específicos e recebem as imagens geradas.

---

## 🏋️ Como usar no contexto "Natty or Not"?

### 1. Imagens Hiper-Realistas de Atletas
O Midjourney é ideal para criar referências visuais de físicos naturais:

```
/imagine prompt: natural male bodybuilder, FFMI 22, realistic physique,
competition stage, professional photography, 8k, photorealistic --v 6 --ar 2:3
```

### 2. Comparativos Visuais
```
/imagine prompt: split image comparison, natural athlete vs enhanced athlete,
educational infographic style, medical illustration, clean background --v 6
```

### 3. Arte Conceitual para Conteúdo
```
/imagine prompt: fitness journey concept art, muscular progression over years,
time-lapse visual metaphor, dark background, dramatic lighting --v 6 --ar 16:9
```

### 4. Capas e Thumbnails
```
/imagine prompt: "Natty or Not" documentary thumbnail, dramatic lighting,
muscular figure silhouette, bold typography space, cinematic --v 6 --ar 16:9
```

## 🎛️ Parâmetros Úteis

| Parâmetro | Função | Exemplo |
|---|---|---|
| `--v 6` | Versão do modelo | Melhor qualidade atual |
| `--ar 16:9` | Proporção da imagem | Para thumbnails/YouTube |
| `--ar 2:3` | Proporção vertical | Para posts Instagram |
| `--style raw` | Menos filtros artísticos | Para fotorrealismo |
| `--q 2` | Maior qualidade (mais lento) | Para resultado final |
