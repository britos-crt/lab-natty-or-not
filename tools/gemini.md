# 🔍 Gemini (Google)

> Modelo multimodal do Google, com acesso integrado à pesquisa web em tempo real.

---

## 🔗 Acesso

- **Site oficial:** [https://gemini.google.com](https://gemini.google.com)
- **API:** [https://ai.google.dev](https://ai.google.dev)
- **Modelos disponíveis:** Gemini 1.0 Pro, Gemini 1.5 Pro, Gemini 1.5 Flash, Gemini Ultra

---

## 📋 O que é?

O **Gemini** é o modelo de IA generativa do Google, integrado ao ecossistema Google (Search, Workspace, YouTube).
Seu grande diferencial é o acesso a **informações atualizadas da web**, tornando-o ideal para pesquisas
sobre tópicos em evolução, notícias recentes e dados atuais do mundo fitness.

---

## 🏋️ Como usar no contexto "Natty or Not"?

### 1. Pesquisa com Dados Atuais
Por ter acesso à web, o Gemini consegue trazer informações recentes:

```
"Pesquise os atletas de fisiculturismo natural mais discutidos em 2024
e os argumentos usados para questionar ou confirmar sua naturalidade."
```

### 2. Análise de Vídeos do YouTube
O Gemini pode analisar conteúdo do YouTube diretamente:
```
"Analise este vídeo sobre fisiculturismo natural e identifique
os principais argumentos apresentados pelo atleta."
```

### 3. Integração com Google Workspace
```
"Crie uma planilha no Google Sheets com os principais indicadores
para avaliar se um atleta é natural (FFMI, % gordura, anos de treino)."
```

### 4. Pesquisa Científica Atualizada
```
"Busque os estudos mais recentes sobre os limites naturais de
hipertrofia muscular publicados nos últimos 2 anos."
```

## ⚠️ Limitações

- A qualidade das respostas pode variar entre modelos (Flash vs. Pro)
- Integração com YouTube pode ter **restrições de direitos autorais**
- Respostas com dados web podem incluir fontes de baixa qualidade
